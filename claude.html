How Claude uses Neuma
  1. Find the Context. Only Contexts the person can open.
  2. Read what Neuma knows. Summary from the latest 10. Issues, actions and decisions from every meeting Neuma has read, each with its quote and link. Most questions stop here.
  3. Search sources. Passages from every transcript and file in the Context, including ones older than the latest 10.
  4. Open a source. The full transcript, when a passage isn’t enough.
Who pays

Neuma pays for reading the latest 10. Searching and opening sources run on the person’s own Claude usage.

Governed
  • Steps 3 and 4 need Full sources on. A switch on each Context, in Share. Only the Owner changes it.
  • Every read is logged. Each search and open goes to the admin audit log.
  • Every claim links back. Citations open the meeting or message in Neuma.

What the Neuma MCP server does, for whoever builds it. Neuma enforces access and serves five tools. Claude does the searching and reasoning on the person’s own usage.

Always a link.YesClaude picks full for questions about the whole meeting, or when passages don’t settle it.
Connection
  • Remote MCP server. Hosted by Neuma. People add it in Claude, ChatGPT or any MCP client from Settings › Your connections › AI tools.
  • Signs in as the person. OAuth with their Neuma account. Every call runs as that person, never as a service account.
  • Read only in v1. No tool changes anything in Neuma.
Every call
  • Check access first. Return only Contexts the person owns or that are shared with them: Owner, Editor, Viewer, or an approved manager request.
  • Super admin doesn’t widen it. A Super admin can open any Context in Neuma, but an AI tool only reaches the ones they own or that are shared with them. Asked about another, the tool says “That Context isn’t shared with you. Open it in Neuma.”
  • Check Full sources. search_sources and get_source need the Context’s switch on. list_sources works without it, since it returns titles, dates and attendees only.
  • Only sources in a Context. Never return anything outside a Context. A removed or deleted source disappears from every tool at once.
  • Log it. Every search_sources and get_source call goes to the admin audit log: person, Context, source, tool, time.
  • Link everything. Every item, passage and source carries a link that opens Neuma at that source, at the timestamp for transcripts.
Errors
  • not_found The Context or source doesn’t exist, or the person can’t open it. One error for both, so nothing leaks.
  • not_shared Super admins only, for a Context they can open in Neuma but that isn’t shared with them. They can already see it exists, so nothing leaks.
  • full_sources_off Include can_turn_on with the Owner’s name, so Claude can say who to ask.
What the AI tool should do
  • Start with get_context. Go to sources only when the question needs quotes, older meetings or detail.
  • Several Contexts match. Answer from each and label the parts. Ask only when the question is unclear.
  • Nothing matches. Say so and list the closest Contexts.
  • Cite. Every claim links to its source.
  • Put these rules in each tool’s description. ChatGPT ignores server-level instructions, so the descriptions are what every client reads.
Later
  • Meaning-based search. Embeddings behind search_sources if keyword search misses things in large Contexts. The tool stays the same.
  • Pin a Context to a Claude Project. Every chat in that project starts from it.
  • Summaries for sources never read. Made the first time someone opens one, then kept.
  • Long-term patterns. Patterns across months, separate from the latest-10 patterns.
  • Write tools. Mark an action done, add a note. Editors only.
ChatGPT
  • Same server, same tools. ChatGPT adds it as a custom connector (an “app”) with the server URL and the same OAuth sign-in.
  • Needs Developer Mode. Not on Free. Business, Enterprise and Edu get full support. Plus and Pro get read-only connectors, which covers ours.
  • Tools only. ChatGPT doesn’t read prompts or resources from MCP servers. Everything goes through the five tools.
  • Deep research and company knowledge. OpenAI has expected tools named search and fetch for these. If still required, add them as aliases for search_sources and get_source. Check OpenAI’s current docs.
  • Searches differently. ChatGPT may retry wordings less than Claude. Watch answer quality. It’s the first reason to add meaning-based search.
  • Test both. A Business workspace and a Plus account. Connector support is still beta and moves often.
