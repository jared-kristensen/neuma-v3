How it answers
  • Answer first. One line that settles the question. Then the dated facts behind it.
  • Linked. Each date links to the meeting, email or file it came from. No quotes in chat.
  • Read only. Slack answers. Changes happen in Neuma through Open in Neuma.
  • Same items as the app. Issues, actions and decisions match the Context page.
  • Several Contexts. When more than one helps, Neuma answers from each and labels the parts. It asks only when the question is unclear.
Who sees what
  • Channels. Neuma uses only Contexts every member of the channel can see.
  • DMs. Neuma uses every Context you can see, private ones included.
  • Private answers. If the channel can’t see the Context, only the asker gets the answer, by DM.
  • Patterns stay in Neuma. Neuma never posts them to Slack.
  • Nothing kept. Neuma reads only the message that mentions it. It never reads channel history or stores Slack messages.
Built from Slack blocks

Every message uses Slack’s own parts: text, buttons and native 👍 👎 feedback. 👍 and 👎 train the ranking, the same as thumbs on the Context page.
